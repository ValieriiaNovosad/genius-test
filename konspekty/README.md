# Конспекти: Професія дата-аналітик (Genius.Space)

Особисті навчальні конспекти за курсом на [edu-new.genius.space](https://edu-new.genius.space/courses/profesiya-data-analityk).

Структуровані тези + mermaid-схеми (не дослівні транскрипти відео).

На платформі: **8 модулів · ~80 лекцій**.

## Прогрес

| Модуль | Тема | Статус |
|--------|------|--------|
| 01 | Вступ до Дата-аналітики | готово |
| 02 | Google Sheets та Excel | готово |
| 03 | Вступ в SQL (MySQL) | готово |
| 04 | Продуктові та маркетингові метрики | готово |
| 05 | Поглиблений SQL (BigQuery) | очікує |
| 06 | Power BI | очікує |
| 07 | Основи Python | очікує |
