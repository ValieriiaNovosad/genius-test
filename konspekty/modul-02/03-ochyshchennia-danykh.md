# 2.7–2.8. Підготовка та очищення даних

> Модуль 2 · «сирі» дані → готові до аналізу

---

## Головна ідея

Без очистки — помилкові метрики й хибні бізнес-рішення. Очистка — **щоденна** робота аналітика, не «разовий ритуал».

```mermaid
flowchart LR
  I[Імпорт CSV/Excel] --> C[Перевірка типів]
  C --> D[Дублі / пропуски]
  D --> N[Нормалізація тексту]
  N --> T[Розумна таблиця]
  T --> A[Аналіз / зведені]
```

---

## 2.7. Імпорт і первинна діагностика

### Як імпортувати

- ❌ Копіпаст великих файлів — ризик кривої конвертації дат/чисел (регіональні коми/крапки).  
- ✅ **Файл → Імпорт** (або завантаження на Диск → відкрити в Sheets) з контролем роздільника й локалі.

### Що перевірити одразу

1. Заголовки на місці, один рядок шапки.  
2. Типи: дати не стали текстом/числами-«сергіями» без потреби.  
3. Панель **статистики** по стовпцю: min/max дат, кількість унікальних, дивні значення.  
4. Фільтри — швидко побачити сміття в категоріях.

Мета частини 1: імпортувати → почистити очевидне → підготувати основу під **розумну таблицю**.

---

## 2.8. Дублі, уніфікація, «розумна таблиця»

### Дублікати

1. Знайти: наприклад `COUNTIF` по ключу (№ транзакції / ID).  
2. Видалити: `Дані → Очищення даних → Вилучити копії` + галочка про рядок заголовків.  
3. Важливо: видаляється **рядок**, не лише комірка.  
4. Ключ дубля обирай свідомо: «Ім’я+Прізвище» часто **не** унікальні; ID транзакції надійніший.

### Уніфікація категорій

- `Змінити → Знайти та замінити` (`так` → `Online`).  
- Або формули `PROPER` / `UPPER` / `TRIM` → **Спеціальна вставка → лише значення**.

### Розумна таблиця

Оформлений діапазон як таблиця: стабільніші діапазони для формул, зведених, фільтрів; менше «поїхав діапазон на 2 рядки».

## Чекліст перед аналізом

- [ ] Немає повних дублів рядків за бізнес-ключем  
- [ ] Дати/числа мають правильний тип  
- [ ] Категорії в одному словнику написання  
- [ ] Немає зайвих пробілів у ключах  
- [ ] Є зрозумілі заголовки без об’єднаних комірок у тілі даних
