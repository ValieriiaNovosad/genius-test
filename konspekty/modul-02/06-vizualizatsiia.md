# 2.11–2.12. Візуалізація даних у таблицях

> Модуль 2 · від метрик до зрозумілого звіту для бізнесу

---

## Головна ідея

Таблицю розуміють аналітики. **Керівник** потребує візуалу: KPI-картки, динаміка, структура. Починай із **запиту бізнесу**, не з «який гарний графік».

---

## 2.11. Запит → метрики → KPI-картки

Приклад метрик зі збутового датасету:

- загальна виручка  
- кількість замовлень  
- середній чек  
- унікальні клієнти  
- динаміка по місяцях  
- продажі по товарах / каналах  

**KPI Scorecard / картка:** велика цифра + коротка назва. Акцент на числі (розмір/жирність), мінімум декоративної рамки.

---

## 2.12. Графіки під тип питання

| Питання | Кращий тип |
|---------|------------|
| Динаміка в часі | Лінійна / площинна |
| Порівняння категорій | Стовпчаста |
| Частки online/offline у часі | Стовпчаста з накопиченням |
| Структура одного періоду | Кругова (обережно, мало категорій) |

### Робочий процес

1. Підготувати **маленьку зведену** під конкретну метрику (не весь сирий факт).  
2. Згрупувати дати по місяцю.  
3. Виділити потрібний діапазон (не зайві підсумки, якщо ламають шкалу).  
4. `Вставити → Діаграма` → обрати тип свідомо, не лише «що запропонував Google».  
5. Підписи, грошовий формат, легенда, заголовок = бізнес-питання.

**Матриця місяць × канал:** дата в рядки, тип замовлення в стовпці/серії → stacked columns для патернів «у якому місяці більше online».
