# 2.4–2.6. Ключові функції для аналізу даних

> Модуль 2 · частини 1–3 · Google Sheets (аналогічна логіка в Excel)

---

## Головна ідея

**Формула** — будь-яке обчислення (`=`, посилання, числа, оператори, функції).  
**Функція** — готова іменована команда з **обов’язковими дужками** (`SUM(...)`).

```text
= A2 + B2          → формула з оператором
= SUM(A2:A100)     → формула, що містить функцію
```

---

## 2.4. Базові формули й посилання

- Оператори: `+ - * /`  
- Автозаповнення вниз (Google часто пропонує протягнути одразу).  
- **Відносне** посилання (`A2`) зсувається при копіюванні.  
- **Абсолютне** (`$A$2` / `$A2` / `A$2`) фіксує рядок/стовпець — критично для коефіцієнтів, курсів, констант.

---

## 2.5. Числові агрегати (щоденний мінімум)

| Функція | Навіщо |
|---------|--------|
| `SUM` | Сума |
| `AVERAGE` | Середнє |
| `MEDIAN` | Медіана (стійкіша до викидів) |
| `MAX` / `MIN` | Екстремуми |
| `COUNT` | Кількість **числових** |
| `COUNTA` | Кількість непустих (будь-який тип) |

**Пастка:** текст, замаскований під число, ламає `SUM`/`COUNT`. Дивись статистику виділення / типи комірок перед здачею звіту.

Шлях у UI: панель **Функції** (згруповані за призначенням) + підказки імен під час введення.

---

## 2.6. Текст, дати, помилки

### Текст (експорти з форм/CRM)

| Функція | Навіщо |
|---------|--------|
| `CONCATENATE` / `&` | Злити ім’я + прізвище |
| `TRIM` | Прибрати зайві пробіли |
| `LEFT` / `RIGHT` / `MID` | Вирізати частини рядка |
| `PROPER` / `UPPER` | Нормалізувати регістр |
| `SUBSTITUTE` | Заміни в тексті |

### Дати

| Функція | Навіщо |
|---------|--------|
| `TODAY()` / `NOW()` | Поточна дата / дата+час (оновлюються) |
| `YEAR` / `MONTH` / `DAY` | Розкласти дату для групувань |
| `DATEDIF` | Різниця між датами |
| `EOMONTH` / `EDATE` | Кінець місяця / зсув місяців |
| `HOUR` / `MINUTE` / `SECOND` | Часові частини |

### Стійкість формул

- `IFERROR(...)` — прибрати «червоні» помилки в звітах для бізнесу (обережно: не маскуй реальні проблеми якості даних).
