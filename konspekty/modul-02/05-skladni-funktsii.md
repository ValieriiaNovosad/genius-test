# 2.10. Складні аналітичні функції

> Модуль 2 · логіка, умови, пошук між таблицями

---

## Головна ідея

Спочатку **проговори умову бізнесу словами**, потім переклади в логіку формул. Це зменшує непорозуміння з замовником і помилки в критеріях.

Фільтри вручну можливі, але для повторюваних правил — **логічні функції**.

---

## Логіка

| Інструмент | Роль |
|------------|------|
| `IF` | Одна умова → два результати |
| `IFS` | Кілька умов послідовно |
| `AND` / `OR` / `NOT` | Складні критерії |
| `COUNTIF` / `COUNTIFS` | Підрахунок за умовою |
| `FILTER` | Повернути відфільтрований діапазон |

**Приклад умови з лекції:** якщо тип замовлення = online → термін доставки 3 дні.

---

## Збагачення даних між аркушами

Часто: аркуш **продажі** + аркуш **клієнти**.

```mermaid
flowchart LR
  P[Продажі + client_id] -->|LOOKUP / XLOOKUP / VLOOKUP| C[Клієнти]
  C --> R[Збагачена таблиця для маркетингу]
```

Правило: джойнити **лише по унікальному ID**, не по ПІБ.

Функції сімейства LOOKUP дозволяють підтягнути сегмент/місто/email клієнта в рядок продажу без ручного копіювання.

Обхід помилок пошуку: `IFERROR` навколо lookup.
