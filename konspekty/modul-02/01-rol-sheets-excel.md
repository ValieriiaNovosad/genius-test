# 2.1–2.3. Роль Google Sheets і Excel у роботі дата-аналітика

> Модуль 2 · Бабець Анастасія · частини 1–3  
> Конспект за лекціями (парафраз, не транскрипт)

---

## Головна ідея

Таблиці — **операційний стіл** аналітика. ≈70% часу роботи з даними проходить у табличному вигляді. Sheets/Excel потрібні для зберігання (на малих обсягах), очистки, зведення, швидких гіпотез і простої візуалізації — особливо на старті задачі.

---

## 2.1. Хмара vs десктоп, анатомія таблиці

### Sheets vs Excel (логіка вибору)

| | Google Sheets | Excel |
|--|---------------|-------|
| Збереження | Автозбереження в хмарі | Локально / OneDrive |
| Співпраця | Реал-тайм коментарі/доступ | Складніше для одночасної роботи |
| Обсяг | Зручно для середніх наборів | Краще тягне дуже великі локальні файли |
| Скрипти | Apps Script | VBA / Power Query |

### Анатомія

```mermaid
flowchart TB
  Book[Книга / файл] --> Sheet[Аркуш]
  Sheet --> Row[Рядки]
  Sheet --> Col[Стовпці]
  Row --> Cell[Клітинка]
  Col --> Cell
```

Базові дії: введення, автозаповнення, копіювання, перейменування аркушів, робота з файлами/Диском.

---

## 2.2. Типи даних і нумерація

**5 основних типів:** число · текст · дата · час · логічне значення.

- **Формат** (як виглядає) ≠ **тип** (як рахується).  
- Керування: `Формат → Число` + швидка панель.  
- Правило аналітика: **довіряй автовизначенню, але перевіряй** — інакше формули «мовчать» або брешуть.

### Нумерація рядків

- Протягування з логікою послідовності (Option/Alt).  
- Краще **динамічно**: формула `=ROW()` (або зсув від заголовка), щоб нумерація не ламалась після сортування/фільтрів.

## 2.3. Оформлення «чистої» таблиці для замовника

Після експорту з CRM/платформ часто «їде» відображення й типи (особливо через регіональні налаштування).

Чекліст приведення до охайного вигляду:

1. Виділити весь датасет швидко (`Ctrl/Cmd+A` у межах даних).  
2. Заголовки: перенесення тексту, **напівжирний**, заливка.  
3. Числові стовпці — **єдиний** формат (однакова кількість знаків).  
4. Ширина стовпців / вирівнювання.  
5. Перевірити, що таблицю можна віддати бізнесу без пояснень «а це чому криво».

---

## Практика

- Завести Google-акаунт / Диск.  
- Скопіювати навчальний файл спікерки (`Файл → Створити копію`).  
- Самостійно: створити аркуш, типи даних, динамічну нумерацію, оформити заголовки.
