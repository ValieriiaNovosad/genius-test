## 6.1. BI і навіщо Power BI

**Business Intelligence (BI)** — підходи й інструменти для збору, обробки, аналізу та візуалізації даних під бізнес-рішення.

Без BI: керівник гортає таблиці / пише запити вручну.  
З BI за секунди: топ товарів, регіони, план продажів, цінні клієнти.

### Чому Power BI популярний (з лекції)

1. **Автоматизація звітності** — оновлення щодня/щогодини замість ручних Excel.  
2. **Об’єднання джерел** — Excel, БД, CRM, веб-сервіси в одній моделі.  
3. **Інтерактив** — drill-down, розрізи (модель / дилер / колір…), зручні переходи між сторінками.

Переваги: інтеграція багатьох джерел, масштабування від малих наборів до корпоративних, відносно простий старт.

```mermaid
flowchart LR
  Src[Джерела] --> Prep[Очистка / трансформація]
  Prep --> Model[Модель]
  Model --> Calc[Розрахунки]
  Calc --> Dash[Дашборд]
  Dash --> Share[Публікація]
```

## 6.2. Встановлення та інтерфейс Desktop

Power BI Desktop ≈ Excel + SQL + сучасна візуалізація в одному середовищі.

### Встановлення

1. **Рекомендовано:** Microsoft Store → Power BI Desktop → Отримати.  
2. Або сайт Microsoft → Advanced download options → інсталятор (мова UI: англійська ок для навчання).

### Інтерфейс

- Вкладка **Home** — найчастіші дії (як у продуктах Microsoft).  
- Блок **Get data** — підключення джерел; швидкі ярлики: Excel, SQL Server, Enter data, Dataverse тощо.  
- Далі: Model / Report / розрахунки (розгортаються в наступних уроках).

### Навчальний датасет (передумова практики)

- **Sales report** — факти продажів + магазин + кількісно-вартісні поля; також операційні витрати й курс валют.  
- **Sales plan / Cost plan** — плани (часто «не ідеальна» форма → тренування трансформацій).  
- Окремі папки по містах (**Київ**, **Харків**) — треба зібрати в єдину модель.

Мета: звикнути, що реальні дані рідко «відразу ідеальні» для star schema.
