# 3.1–3.2. SQL, типи БД і середовище MySQL

## Головна ідея

БД — фундамент сучасного бізнесу. Аналітик працює переважно мовою **SQL** над **реляційними** таблицями. Спочатку зрозумій модель даних і інструменти, потім пиши запити.

---

## 3.1. Дані → інсайти, SQL, типи БД

Ланцюг цінності:

```mermaid
flowchart LR
  D[Дані] --> I[Інформація]
  I --> K[Знання]
  K --> Insight[Інсайт / рішення]
```

### Реляційна модель

- Дані в **таблицях** (рядки = записи, стовпці = атрибути з типами).  
- Зв’язки через ключі.  
- SQL — стандартна мова доступу.

### Реляційні vs нереляційні (NoSQL)

| | Relational | NoSQL |
|--|------------|-------|
| Структура | Таблиці, схема | Документи/ключ-значення/графи… |
| Запити | SQL | Різні API |
| Аналітика | Класичний вибір аналітика | Часто для спецкейсів/продукту |

Популярні SQL-рушії в проєктах: MySQL, PostgreSQL, BigQuery, SQL Server тощо (діалекти близькі, але відрізняються).

---

## 3.2. Стек для навчання

Три компоненти:

1. **MySQL Server** — сама БД (таблиці, дані).  
2. **MySQL Workbench** — GUI/СУБД-клієнт: пишеш SQL, бачиш результат.  
3. **Dataset Employees** — навчальна схема «компанія / співробітники».

Встановити сервер → Workbench → імпортувати employees → перевірити підключення `MySQL80`.
