## 3.5. Логіка SELECT

Базовий каркас:

```sql
SELECT column1, column2
FROM schema.table;
-- або SELECT * (обережно на великих таблицях)
```

Порядок **написання** ≠ порядок **виконання**. Для простого запиту з фільтром логіка виконання:

`FROM → WHERE → SELECT` (далі з’являться GROUP BY / HAVING / ORDER BY / LIMIT).

Добрі звички: коментарі в файлі запиту, збереження `.sql` у Workbench, не тягнути `*` без потреби.

## 3.6–3.7. Фільтрація WHERE

```sql
SELECT *
FROM employees.salaries
WHERE salary > 100000;
```

Оператори порівняння: `= != <> > >= < <=`  
Логіка: `AND`, `OR`, `NOT`  
Часті патерни: `IN (...)`, `BETWEEN ... AND ...`, `LIKE`, `IS NULL` / `IS NOT NULL`

Аналогія: фільтр у Excel, але виконується на сервері до вигрузки.

Практика: новий Query Tab, зберегти файл `lesson_where.sql`, багаторядковий коментар з датою/автором, серія умов на `employees`.
