# 8.9–8.12. Коли результат випадковий

> Модуль 8 · 4 уроки (2 теорії + 2 практики)

---

## Головна ідея

Зростання метрики на дашборді **може бути шумом**. Статистика допомагає оцінити, чи різниця між групами / періодами правдоподібна як випадковість.

Ключові поняття (рамка курсу):
- випадковість vs систематичний ефект;
- p-value / рівень значущості як мова «наскільки дивно бачити таке під H₀» (деталі — з лекції);
- розмір вибірки: малий N → легко «знайти» фейковий uplift;
- множинні порівняння: чим більше розрізів, тим більше хибних «перемог».

```mermaid
flowchart LR
  Obs[Побачили різницю] --> Q{Може бути шум?}
  Q -->|так| Test[Перевірка / більше даних]
  Q -->|ні / стійко| Act[Рішення продукту]
```

Практика 8.11–8.12: порахувати / інтерпретувати на навчальних даних, не плутати «стат. значуще» з «бізнесово важливе».
